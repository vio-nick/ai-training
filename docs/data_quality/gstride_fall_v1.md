# GSTRIDE 跌倒者识别数据质量报告：v1

本报告对应 `data/public/gstride_v1/processed/` 下由构建脚本生成的特征表和切分表。机器可读的完整元数据见 `gstride_fall_v1_quality.json`。

## 完整性与范围

- 参与者数：163；参与者 ID 唯一且非空。
- 标签：86 个 `1`、77 个 `0`；无未知标签。
- 六项特征均无缺失。
- 特征范围：步速 0.120–1.607 m/s；步频 24.010–66.370 strides/min；跨步长 0.291–1.530 m；双支撑 14.050–39.580%；摆动/支撑比 0.0885–0.5392；步态时间变异度 2.3166–20.2974%。

范围用于发现导入、单位或解析错误，不作为临床正常值界限。

## 切分审计

切分由 `make_stratified_split` 按标签分层、按参与者 ID 打乱，固定随机种子 `20260907`，比例为 60%/20%/20%。结果为训练 98、验证 32、测试 33；同一参与者不会跨越切分。模型预处理只在训练集拟合，阈值只使用验证集选择，测试集不参与模型选择。

## 已知风险

标签为回顾性自报，可能有回忆偏倚；样本量小，且采集场地、功能状态和辅助设备差异可能造成混杂。质量检查通过不等于数据具有代表性，也不等于模型可用于临床或前瞻性跌倒预警。
