# 数据质量报告：nhanes_2013_2018_public_v2

本报告只评价 CDC/NCHS 两个 NHANES 周期的工程质量和探索性建模适用性，不代表24个月骨折风险性能。

## 样本与标签

| 项目 | 数值 |
| --- | ---: |
| 合并样本 | 1771 |
| `fracture_history=0` | 1362 |
| `fracture_history=1` | 409 |
| 2013–2014 | 904 |
| 2017–2018 | 867 |
| 训练/验证/测试 | 1062/354/355 |

标签来自 `OSQ080` 既往骨折史，未包含事件日期和未来观察窗。它不能用于证明模型预测未来骨折。

## 缺失与选择性

| 字段组 | 缺失数量 | 处理 |

| 腰椎/骨盆 BMD | 366 | 训练集内中位数 + 缺失指示器 |
| 头部 BMD | 239 | 训练集内中位数 + 缺失指示器 |

| 糖尿病 | 60 | 训练集内中位数 + 缺失指示器 |

缺失不是随机缺失的证据尚未完成，DXA 子样本和问卷适用条件可能引入选择偏倚。完整缺失统计、源文件哈希和输出哈希见 `nhanes_exploratory_v2_quality.json`。

## 可接受范围与阻塞项

- ID 唯一、周期可追溯、标签只保留明确1/0，且切分 ID 与特征表一致。
- NHANES `WTMEC2YR` 被保留并用于相对加权；本项目没有使用复杂抽样方差估计，因此结果不应解释为全国总体推断。
- 年龄覆盖受 OSQ 设计限制，主要为50–59岁；这仍是外推和泛化的阻塞项。
- 横断面既往骨折标签与24个月正式终点不匹配，是研究结论的阻塞项，不能通过调参解决。
