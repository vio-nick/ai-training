# 数据版本：nhanes_2013_2018_public_v2

## 用途与终点边界

- 来源：CDC/NCHS NHANES 2013–2014 与 2017–2018 public-use 文件。
- 用途：扩大公开探索样本，并验证索引时点临床风险变量对横断面历史骨折标签的影响。
- 主标签：`fracture_history`，由 `OSQ080` 的 1/2 编码得到。
- 重要限制：`OSQ080` 是既往骨折史，没有事件日期、骨折性质或索引时点后的观察窗，因此不是项目要求的24个月骨质疏松性骨折终点。
- 许可与合规：公开文件须遵守 CDC/NCHS 数据使用说明、引用要求和再分发限制；本版本不含姓名、联系方式或精确地址等直接身份信息。

## 文件来源

每个周期使用 DEMO、BMX、OSQ、DXX 以及 MCQ、SMQ、ALQ、PAQ、BPQ、DIQ。官方文件页面规则为：

`https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/<year>/DataFiles/<file>_<suffix>.xpt`

其中2013–2014使用 `<year>=2013`、`<suffix>=H`，2017–2018使用 `<year>=2017`、`<suffix>=J`。原始文件位于：

- `data/public/nhanes_2013_2014/raw/`
- `data/public/nhanes_2017_2018/raw/`
- `data/public/nhanes_aux/raw/`

完整的文件 SHA-256 记录在 `data/public/nhanes_2013_2018/processed/nhanes_exploratory_v2_quality.json`，避免在此处复制易错的长哈希。

2015–2016 的 DEMO/BMX/DXX 文件曾用于兼容性核验，但 CDC 公开目录没有对应的 `OSQ_I` 文件，因此该周期没有进入 v2 训练样本；相关核验文件不构成 v2 数据来源。

## 处理规则

1. 仅保留年龄不低于50岁、年龄/性别/BMI有效且 `OSQ080` 为明确“是/否”的受试者。
2. 两个周期按 `SEQN` 合并；输出 ID 加入周期后缀，确保跨周期不重复。
3. `1` 映射为是，`2` 映射为否；问卷拒答/不知道编码保留为空，由训练管线拟合缺失处理。
4. 只使用索引时点可得的人口学、BMD、吸烟、饮酒、体力活动、血压、糖尿病和心脑血管病史字段；不使用 OSQ 的骨折部位、年龄或事件细节字段。
5. BMD 与问卷字段缺失不进行全表删除；数值字段使用训练集内中位数和缺失指示器，分类字段使用显式缺失类别。
6. 数据切分按标签分层、按个体隔离，随机种子为 `20260808`，比例为60%/20%/20%。

## 当前规模

- 总样本：1771；标签0/1：1362/409。
- 周期：2013–2014为904，2017–2018为867。
- 训练/验证/测试：1062/354/355。
- 年龄范围仍主要为50–59岁，这是OSQ问卷可用人群限制，合并周期没有改变这一限制。

## 不可替代项

该版本改善的是公开横断面探索的样本量、特征覆盖和评估稳定性，不是正式临床数据替代品。若项目必须报告24个月未来骨折，仍需获批的纵向队列、索引日期、事件日期和删失规则；在此之前不得将 v2 指标写成24个月风险性能。
