# 数据版本：synthetic_v1

## 状态与用途

- 状态：可公开共享的合成开发数据。
- 用途：验证成员 A 的数据处理、质量检查、特征表、切分与传统基线工程流程。
- 禁止用途：临床性能评估、真实人群推断、医学结论、模型卡中的正式性能声明。
- 负责人：成员 A。
- 生成方式：固定随机种子 `20260808` 的 `scripts/generate_synthetic_data.py`。

## 来源与合规

该版本由代码在本仓库内生成，不包含真实受试者、个人身份信息、访问令牌或受限材料。可随本仓库共享和再分发。其变量范围仅为工程测试而设，不对应任何真实医疗机构或患者群体。

## 已知限制

- 标签、特征分布和缺失机制均为人工设定，不能代表真实骨质疏松性骨折风险。
- 不包含中心、设备、随访时间或真实临床工作流带来的偏倚。
- 本版本仅冻结开发接口；正式数据版本必须另行记录来源、许可/伦理状态、去标识化审查和变更影响。
