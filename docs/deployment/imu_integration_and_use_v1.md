# IMU 接入与使用说明：GSTRIDE 跌倒者识别原型 v1

**适用版本：** `gstride_fall_v1`

**读者：** IMU 算法/嵌入式/应用工程师、研究操作人员和项目使用者

**状态：** 研究原型接入规范，不是医疗器械使用说明

## 1. 用途和重要限制

本模型的训练标签是“受试者在步态测试前一年内是否自报发生过跌倒”。模型输出仅表示六项步态参数在公开 GSTRIDE 数据中与**既往自报跌倒者**的关联分数。

它不是未来跌倒概率、骨折风险、骨质疏松风险、诊断结果、筛查结论或治疗建议。不得将结果用于医疗决策、分诊、报警、保险、就业或其他高影响个人决策。

仓库已完成六项步态特征的研究原型训练与评估，但尚未完成 IMU 设备等效性验证、目标人群前瞻性验证、外部验证或医疗器械合规评估。真实用户使用前，必须先完成第 9 节的发布前验收。

## 2. 系统边界与责任

模型不接收原始 IMU 波形。接入系统必须先用独立、经验证的步态事件检测和参数计算链路，将一次标准化步行测试转换成规定的六个汇总参数；只有这些参数进入模型。

```text
IMU 原始信号
  -> 佩戴和信号质量检查
  -> 步态事件/步态周期识别
  -> 六项 GSTRIDE 参数汇总
  -> 单位和字段映射、输入校验
  -> 已封版模型推理
  -> 质量状态、审计记录和受控展示
```

| 角色 | 职责 |
| --- | --- |
| IMU/算法工程师 | 固定设备、佩戴位置、采样配置、事件算法和参数计算；证明输出与 GSTRIDE 口径等效。 |
| 模型接入工程师 | 只将契约字段送入已封版模型；执行版本、类型、单位、缺失值、审计和异常处理。 |
| 研究操作人员 | 按批准方案采集；确认测试有效，在质量失败时安排重测。 |
| 合规/项目负责人 | 确认伦理、知情同意、隐私、适用场景和任何结果展示的批准。 |
| 使用者 | 配合标准化采集；不得把界面分数理解为诊断或未来风险承诺。 |

## 3. 固定输入契约

每条推理记录对应一次**通过质量检查的标准化步行测试**。数据版本必须精确为 `gstride_fall_v1`。字段名、定义和单位不得改变；不得以同名但定义不同的设备指标替代。

| 字段 | 类型和单位 | GSTRIDE 口径 |
| --- | --- | --- |
| `participant_id` | 非空字符串，建议传入 | 仅用于追踪和审计，不参与计算。 |
| `step_speed_m_s` | 浮点数，m/s | `Step Speed Avg`。 |
| `cadence_strides_per_min` | 浮点数，strides/min | `Cadence Avg`；不可替换为 steps/min。 |
| `stride_length_m` | 浮点数，m | `Stride Length Avg`。 |
| `double_support_pct` | 浮点数，% | `Load Avg + Push Avg`；传入 0--100 百分数，不能传 0--1 比例。 |
| `swing_to_stance_ratio` | 浮点数，无量纲 | `Swing Avg / (Load Avg + Foot Flat Avg + Push Avg)`。 |
| `stride_time_cv_pct` | 浮点数，% | `100 * Stride Time Std / Stride Time Avg`；传入 0--100 百分数。 |

`faller_last_year` 是训练和离线评估标签，**绝不能**作为 IMU 推理输入或从设备端推断。可保留在受控研究数据中，但推理接口不会读取它。

```json
{
  "participant_id": "session-20260908-001",
  "step_speed_m_s": 1.353,
  "cadence_strides_per_min": 59.01,
  "stride_length_m": 1.213,
  "double_support_pct": 32.3,
  "swing_to_stance_ratio": 0.470813679245283,
  "stride_time_cv_pct": 7.045009784735812
}
```

调用时还必须显式传递 `data_version="gstride_fall_v1"`。字段少于六项、值无法转换为数值、存在无穷值或版本不一致时，`FallerInferenceModel` 会拒绝请求。

## 4. IMU 参数链路标准

### 4.1 设备与算法等效性

训练数据来自 GSTRIDE 注册表的步态参数，不等同于任意 IMU 算法的输出。上线前必须冻结并记录：传感器型号和固件、佩戴位置与方向、采样率、滤波和坐标变换、步态事件定义、有效步数规则、异常步处理、参数汇总方法和软件版本。

不得仅因字段名称相同就认定设备输出与训练输入等效。应使用同时具有参考测量和 IMU 记录的独立验证集，对六项参数逐项评估偏差、一致性和失败率。若定义、单位、测试任务或人群不同，必须重新训练或至少重新校准并发布新版本，不能继续声明兼容 `gstride_fall_v1`。

### 4.2 单次采集的最低处理要求

1. 按经批准的统一测试方案完成步行测试，记录测试方案、设备、算法版本和时间戳。
2. 在参数计算前检查传感器连接、采样完整性、饱和/丢包、佩戴状态和可用步态周期数。
3. 仅用被接受的完整步态周期计算六项指标，记录被排除周期及原因。
4. 不得将缺失周期、失败事件或无法测量的指标填为零；不得静默截断、转换单位或把步频替代为跨步频率。
5. 将最终参数与原始质量状态一起保存。质量失败必须返回“采集无效/需要重测”，不得产生模型分数。

模型在离线训练中包含中位数插补，因此技术接口可以接受缺失值；但 IMU 实际接入标准应更严格：六项参数均须有效且有限。任何缺失、单位不明、设备质量不合格或超出已验证设备范围的记录，都不得自动评分。

### 4.3 建议的审计数据

除六项模型输入外，系统应独立保存 `measurement_id`、`participant_id`、采集时间、设备/固件版本、算法版本、测试方案版本、每项参数质量标志、总体质量状态和操作者标识。审计字段不得意外送入模型，也不得替代六项特征。

## 5. 推理、输出与阈值

### 5.1 模型封版要求

仓库提供可复现的训练和推理代码，但没有可直接投产的通用模型二进制包。部署团队必须从固定配置生成候选模型并建立不可变发布包，至少包括：

- 经审批的序列化模型及其 SHA-256；
- `gstride_fall_v1` 输入契约和字段顺序；
- 训练配置及其 SHA-256；
- 模型名称、训练数据版本、Python/scikit-learn 版本和发布日期；
- 验证集阈值、阈值选择规则和适用范围；
- 本说明、模型卡和已知限制。

不得在客户端或设备端使用新采集数据重新拟合插补器、标准化器、阈值或模型。模型、预处理器和阈值必须作为同一发布包原子更新；任一项变化均视为新模型版本。

现有工作流以随机森林作为推理示例。其工程回归参考阈值为 `0.388417`，来自固定验证集“最大平衡准确率”选择，不能理解为通用医疗阈值。该候选模型在 33 人固定测试集上的敏感度为 0.8235、特异度为 0.7500、AUROC 为 0.7868、AUPRC 为 0.8030；样本很小，不能外推到新设备、人群或场景。

### 5.2 调用与返回格式

推理使用 `FallerInferenceModel.predict_record` 或 `predict_frame`。接口只从请求中选择六项特征，并复用训练时已拟合的预处理器。

```python
result = deployed_model.predict_record(
    imu_gait_features,
    data_version="gstride_fall_v1",
)
```

| 返回字段 | 含义 |
| --- | --- |
| `participant_id` | 若传入则原样返回，用于关联。 |
| `predicted_probability` | 对训练标签“既往一年自报跌倒者”的模型分数，不是未来跌倒概率。 |
| `predicted_probability_percent` | 与 `predicted_probability * 100` 完全对应的 0%--100% 展示值。 |
| `risk_level` | 固定展示分级：低风险 `< 30%`；中风险 `30%--70%`（含 30%、70%）；高风险 `> 70%`。这是研究原型的分段，不是临床验证的风险分层。 |
| `risk_level_display` | `risk_level` 的中文展示值：低风险、中风险或高风险。 |
| `predicted_label` | `predicted_probability >= decision_threshold` 的技术标记，不是风险等级或临床阳性结论。 |
| `decision_threshold` | 当前封版模型阈值，必须随结果记录。 |
| `data_version` | 必须是 `gstride_fall_v1`。 |
| `model_name` | 产生结果的候选模型名称。 |

应用层应额外返回或存储 `quality_status`、`model_release_id`、`measurement_id` 和错误代码。展示时可将 `predicted_probability_percent` 保留一位小数；判定必须使用未经四舍五入的 `predicted_probability`，以避免边界值被错误分级。输入校验失败、模型文件校验失败或质量失败时，必须返回可处理的失败状态，不能返回默认 0 分、低风险或历史缓存结果。

## 6. 面向操作人员和使用者的展示规则

采集前应说明这是研究原型，结果不用于诊断或预测未来跌倒。操作人员应先确认采集是否成功、是否需要重测，不能引导使用者围绕分数作出健康或生活决定。

在完成第 9 节验证和相应合规批准前，面向一般使用者的界面应显示采集状态和研究同意信息，不应显示“高/中/低跌倒风险”、红绿灯、医疗建议、骨质疏松或骨折暗示。若获批在研究工作台展示模型结果，应同时显示：

> 此结果是基于六项步态参数的研究分数，用于识别公开数据中与既往自报跌倒史相关的模式。它不能预测未来跌倒，不能用于诊断、筛查或医疗决策。

任何对结果的回访、转介或人工复核流程必须由已批准的研究方案或临床治理流程定义，不能由应用开发者自行设定。

## 7. 异常处理与运行监控

| 情况 | 必须执行的动作 |
| --- | --- |
| 传感器掉线、饱和、丢包、佩戴不合格或有效步态周期不足 | 标记采集无效；保留原因；按方案重测；不运行模型。 |
| 六项中任一项缺失、非数值、无穷值、单位未知或版本不匹配 | 拒绝推理；返回字段级错误；不填零、不猜测单位。 |
| 参数计算逻辑、设备型号/固件、佩戴方案或测试协议变更 | 停止沿用当前模型声明；完成等效性评估并按结果新建模型/数据版本。 |
| 模型包哈希、配置哈希或依赖版本不匹配 | 阻断评分，回滚到已批准发布包或完成重新验证。 |
| 分数异常集中、质量失败率升高或新用户群明显不同 | 触发数据漂移审查；只记录质量和分布变化，不能误报为性能。 |

运行日志必须可追溯到模型发布包、输入版本、质量状态和失败原因。日志和特征数据属于敏感健康相关数据，应采用最小化收集、去标识化、访问控制、传输与静态加密、保留期限和删除流程；具体要求由适用法规、伦理审批和数据使用协议确定。

## 8. 禁止事项

- 不得将 `predicted_probability` 重命名为“未来跌倒风险”或“骨折风险”。
- 不得用该模型诊断、筛查或判断骨质疏松，也不得以 BMD、医院数据或其他临床变量模拟“融合结果”。
- 不得以设备端采集数据自动再训练、自动调阈值或自动校准。
- 不得将另一种 IMU 算法、步态任务或不同单位的输出直接接入而不做等效性验证。
- 不得因模型标记为 0 向使用者保证安全，或因标记为 1 作出医疗、运动限制或其他高影响建议。

## 9. 上线/试运行前验收

- [ ] 已确认场景是获批的研究或工程试运行，不是诊断、筛查或治疗用途。
- [ ] 已冻结设备、固件、佩戴、测试协议和参数计算算法，并留存版本信息。
- [ ] 已在独立配对数据上验证 IMU 与六项 GSTRIDE 口径的等效性，审查单位、定义、偏差和失败率。
- [ ] 每条评分记录均通过六项完整输入、有限值、单位和 `gstride_fall_v1` 版本校验。
- [ ] 已生成哈希校验通过、可追溯的模型发布包；预处理器、模型和阈值来自同一封版。
- [ ] 已完成仓库单元测试和部署环境的端到端回归测试。
- [ ] 已完成权限、同意、去标识化、加密、日志、保留和删除策略审查。
- [ ] 已定义质量失败、输入拒绝、模型校验失败和设备/算法变更的阻断与回滚流程。
- [ ] 已完成目标人群和目标设备上的前瞻性/外部验证、校准、亚组评估和适用合规审查，方可考虑任何临床相关展示或声明。
