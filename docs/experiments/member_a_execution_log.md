## 已识别风险与处理

- 真实数据缺失：使用合成数据只验证工程流程，所有正式结论保持阻塞。
- 正式接口未共同确认：将发布 `v1` 合成开发契约，并在交接文档中标注需成员 B 确认。
- Python 机器学习依赖缺失：在依赖清单中固定版本，安装后再执行基线与测试。
- NHANES 终点不匹配：`fracture_history` 为横断面既往史，不能替代 24 个月骨折终点。
- NHANES 基线性能弱：测试 AUROC 约 0.49–0.56，特异度约 4%–7%，当前特征组合不支持筛查使用。

## NHANES v2 结果弱问题改进记录（2026-08-08）

### 改动目标

针对 v1 样本量较小、BMD 缺失、临床风险变量不足、调查权重未使用以及 F1 阈值导致低特异度等问题，新增公开数据探索版本 v2。此次改动的目标是改善工程评估和横断面标签的可分性，不把 NHANES 横断面数据伪装成项目正式的24个月终点。

### 数据与特征改动

- 合并 NHANES 2013–2014 与 2017–2018 两个兼容周期，生成 `nhanes_2013_2018_public_v2`。
- 样本由 v1 的865行增至1771行，标签 `0/1` 为1362/409，训练/验证/测试为1062/354/355。
- 在人口学和BMD特征外，加入索引时点可获得的吸烟、饮酒、体力活动、高血压、糖尿病、冠心病、心肌梗死和卒中字段，并保留 `osteoporosis_diagnosis` 与调查周期。
- BMD和问卷缺失不再通过全表删除处理：数值特征使用训练集内中位数并增加缺失指示器，分类缺失使用独立类别。
- 保留 `WTMEC2YR`、分层和PSU元数据；训练和评估使用归一化相对权重，但未进行复杂抽样方差估计。
- 核验过 NHANES 2015–2016 的 DEMO/BMX/DXX 文件，但官方目录没有对应的 `OSQ_I`，因此没有混入 v2 标签数据。

### 结果与审查

| 特征集 | 重复5折×3次加权 AUROC | 加权 AUPRC | 加权 Brier |
| --- | ---: | ---: | ---: |
| 基础人口学+BMD | 0.5475 | 0.3263 | 0.2484 |
| 扩展临床风险特征 | 0.6480 | 0.4242 | 0.2315 |

固定测试集上，扩展逻辑回归 AUROC 为 `0.6150`、AUPRC 为 `0.3713`、固定0.5阈值特异度为 `0.7002`；扩展随机森林 AUROC 为 `0.6109`、AUPRC 为 `0.3763`、固定0.5阈值特异度为 `0.6669`。阈值选择改为验证集特异度至少0.5时最大化敏感度，同时保留固定0.5阈值，避免旧版 F1 搜索产生全阳性预测。

审查结论：工程性因素造成的弱结果已得到部分缓解，扩展特征在重复交叉验证中表现出稳定改善；10项自动化测试通过，新增中文文档均通过 UTF-8 检查。NHANES 仍主要覆盖50–59岁，BMD/问卷存在选择性缺失，且 `OSQ080` 仍是横断面既往骨折史，没有事件日期和24个月观察窗。因此，本次结果只能作为公开探索性证据，正式24个月模型任务仍需获批纵向队列后重建标签并重新验证。
