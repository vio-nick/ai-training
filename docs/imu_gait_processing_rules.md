# IMU 步态模型处理固定规则

本规则用于把已标定的 CSV IMU 数据送入 GSTRIDE 步态算法，并将结果转换为仓库固定模型的六项输入。固定规则依据仓库中的原始 GSTRIDE 主流程和训练特征构建代码。训练集仅保留汇总后的 `Database_register.csv`；仓库没有训练参与者逐周期 IMU 波形，因此不把无法从代码或训练表验证的周期边界假设写入主流程。

## 固定主流程

1. **读取和单位转换**：原始日志转换步骤按文件头单位将毫秒转秒、陀螺仪度每秒转弧度每秒；加速度保留为米每二次方秒。它将数据写为适配器规定的列格式。`csv_adapter.py` 校验列名、数值和时间戳，不负责设备标定矩阵。已完成设备标定的数据不得重复标定；尚未标定的数据应先完成与该设备对应的标定。本次 `data/test/opt` 没有可用的设备标定资料，因此没有套用其他 GSTRIDE 设备的标定矩阵，相关结果属于技术诊断。
2. **重采样**：适配器要求时间戳严格递增；最大缺口默认不得超过 30 ms。符合条件的数据线性插值到 100 Hz，超限则输入质量检查失败。
3. **运行 GSTRIDE 主算法**：运行仓库 Mahony AHRS、`StepDetection_MultiCorrector_Pitch`、`INS_ZUPT` 和 `Gait_Parameters_Estimation`。ZUPT 锚点固定使用主流程的 `midFF`，并要求锚点数与检测周期数相符。CSV 适配器是必需的数据接入层，不是另一种算法结果；不输出周期起点锚点作为并列主结果。
4. **周期质量检查**：相位索引必须严格递增；周期时间限于 0.5–3.0 秒，跨步长限于 0.05–2.0 米，步速限于 0–3.0 米每秒。记录所有失败周期及原因；有效周期少于 3 个则不生成模型输入。
5. **按训练口径汇总**：在通过质量检查的候选周期上，对周期时间、步频、步速、跨步长、Load、Swing、Push 和 Foot Flat 各自独立调用 GPE 的 `trunc_array`。当前函数的 `limit=0.4`，对正中位数实际保留中位数 40%–140% 区间内的值。每项至少保留 3 个值；记录每个特征的保留数量和周期索引。不得把八项指标先合并成共同周期集。
6. **复现训练表精度并派生特征**：周期时间均值和标准差、步频、步速、跨步长采用 3 位小数；相位百分比均值采用 2 位小数。再按训练特征构建代码计算：

   - `step_speed_m_s = Step Speed Avg`
   - `cadence_strides_per_min = Cadence Avg`
   - `stride_length_m = Stride Length Avg`
   - `double_support_pct = Load Avg + Push Avg`
   - `swing_to_stance_ratio = Swing Avg / (Load Avg + Foot Flat Avg + Push Avg)`
   - `stride_time_cv_pct = 100 * Stride Time Std / Stride Time Avg`

7. **固定模型推理**：通过封版模型和仓库 `score_records` 推理代码计算。低/中/高展示区间与模型的二元决策阈值是不同输出；模型标签定义为测试前一年内自报跌倒史，分数不能解释为未来跌倒概率、临床风险或诊断。

## 末尾静止与周期边界

保留结尾静止段有助于步态事件检测识别最后的完整相位。周期只有在既定的相位和生理范围质量检查失败时才被排除。单纯与陀螺仪静止片段重叠，不触发整周期删除；该额外排除可以作为有明确标注的敏感性分析，不能替代主结果。

这一选择避免把没有训练波形依据的末尾删周期策略伪装成训练一致规则。若将来取得训练原始波形、设备标定资料或验证后的终止边界规则，应另行评估并版本化，不应默默改变本流程。

## 结果解释

模型与测试数据特征来源于不同传感器、采集方案和处理链的可能性尚未被本仓库的模型评估解决。评分适合当前技术诊断和管线检查；正式设备或临床使用前，应验证标定、佩戴位置、任务协议、特征等效性和外部预测性能。
