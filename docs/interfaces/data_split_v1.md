# 数据切分接口：v1

## 文件格式

切分清单为 `data/splits/split_v1.csv`，采用 UTF-8 CSV，包含且仅包含以下列：

| 列名 | 类型 | 允许值 | 说明 |
| --- | --- | --- | --- |
| `participant_id` | string | 特征表中的唯一 ID | 用于与特征表关联 |
| `split` | category | `train`、`validation`、`test` | 固定数据集合 |

## 生成规则

- 版本：`split_v1`。
- 随机种子：`20260808`。
- 目标比例：训练 60%，验证 20%，测试 20%。
- 分层变量：`fracture_within_24m`。
- 隔离维度：`participant_id`。每个 ID 只能出现一次，且只能属于一个集合。
- 正式数据出现同一参与者的重复测量、时间序列或多中心样本时，必须发布新版本，补充参与者、时间或中心隔离策略。

## 防泄漏边界

切分完成后，插补、分类编码、标准化、特征选择和模型调参只能在训练集拟合。验证集只用于选择已预先定义的候选方案；测试集只用于一次或预先登记的最终评估。任何例外都必须在实验记录中说明并发布新的切分或实验版本。

## 完整性校验

- 清单 ID 与特征表 ID 集合完全相同；
- 不存在重复 ID、空 ID 或未知集合标签；
- 每一类标签在各集合中至少有一个样本；
- 实际比例、样本量和阳性比例写入数据质量报告与实验记录。
