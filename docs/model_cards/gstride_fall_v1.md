# 模型卡：GSTRIDE 跌倒者识别 v1

## 模型概述

这是一个使用六项足部传感器汇总步态参数的研究原型，用于识别测试前一年内报告过跌倒的参与者。当前实现包含逻辑回归和随机森林两个基线，代码与配置分别位于 `src/fall_prediction/`、`scripts/run_gstride_fall_baseline.py` 和 `configs/gstride_fall_v1.json`。

## 数据与训练

数据来自 GSTRIDE v1.0（Zenodo DOI `10.5281/zenodo.8003441`），共 163 人，标签为回顾性自报跌倒史。固定参与者级切分为训练 98、验证 32、测试 33。训练集使用 5 折 × 5 次重复分层交叉验证作稳定性参考；阈值仅根据验证集平衡准确率选择。

## 最近一次结果

环境为 Python 3.13.9、scikit-learn 1.7.2。固定测试集结果：逻辑回归 AUROC 0.7868、AUPRC 0.7771、敏感度 0.8824、特异度 0.6250；随机森林 AUROC 0.7868、AUPRC 0.8030、敏感度 0.8235、特异度 0.7500。完整指标、阈值和预测文件见 [`docs/experiments/gstride_fall_v1.md`](../experiments/gstride_fall_v1.md) 与 `reports/baselines/`。

这些数字来自 33 人的单次固定测试集，不能视为外部验证、临床性能或可推广性证据。

## 概率与展示分级

推理输出包括 0--1 的 `predicted_probability` 及其 0%--100% 表示 `predicted_probability_percent`。为统一工程展示，原型按未经四舍五入的概率分为：低风险 `< 0.3`（低于 30%）、中风险 `0.3--0.7`（30% 至 70%，含边界）、高风险 `> 0.7`（高于 70%）；相应输出 `risk_level` 和中文 `risk_level_display`。

这些等级仅是对当前回顾性模型分数的展示分段，不能被称为经验证的未来跌倒风险等级。`predicted_label` 仍按各封版模型的验证集 `decision_threshold` 计算，不能用 0.3/0.7 分级边界替换。

## 限制与禁止用途

标签存在回忆偏倚，样本量和人群覆盖有限，且数据为横断面/回顾性组合。模型不能用于预测未来跌倒、判断骨折或骨质疏松风险、诊断、治疗决策、筛查分流或替代医务人员。部署前必须取得合规医院纵向数据，重新定义前瞻性终点，完成时间外验证、校准、亚组公平性与伦理监管评估。

## 后续升级
