# GSTRIDE 评估工作台

React + TypeScript + Vite，Tailwind CSS + shadcn/ui，React Hook Form + Zod，Recharts。

## 开发

先按 [API 启动说明](../api/README.md) 在仓库根目录生成模型并启动 8000 端口的服务。另开终端：

```sh
cd frontend
npm ci
npm run dev
```

访问 http://127.0.0.1:5173 ，点击“填入示例”，再点击“开始评估”。示例仅是演示输入，不是个人记录。页面通过 `/api/predict` 调用真实模型，不使用模拟评分。

开发代理在 `vite.config.ts`：`/api/*` 转发到 `http://127.0.0.1:8000/*`。更换后端端口时修改此配置。

## 生产构建

```sh
npm run build
```

`dist/` 是静态产物。实际部署需要服务器将 `/api/*` 转发给 FastAPI 并移除 `/api` 前缀，同时托管 `dist/`；Vite 开发代理不随静态产物部署。当前没有部署到公网。

## 范围

- 六项步态参数、可选记录编号、单位说明、字段级校验。
- 示例填充、重置、等待/加载/成功/失败状态、30 秒请求超时。
- 真实评分、展示分组、正负特征贡献图及可展开的数值明细。
- 修改参数后保留并标记上次结果；显示本次提交编号及模型版本。
- 桌面双栏、手机单栏；表单可键盘操作，错误关联输入，图表有表格替代。

不包含设备通信、历史保存、文件上传或报告导出。刷新页面会清空本次输入和结果。
